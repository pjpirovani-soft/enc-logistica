# CONTROL DE USO DEL VEHÍCULO (TOYOTA RACTIS)

## 1. Límites de Carga
- Carga útil máxima: 350 kg.
- Acomodar los paquetes más pesados en el piso del baúl, no sobre otros paquetes.
- No bloquear la visibilidad trasera.

## 2. Registro de Combustible (Obligatorio)
- Anotar el kilometraje cada vez que llenes el tanque en Petropar (o estación de preferencia).
- Fórmula: (Kilometraje final - Kilometraje inicial) / Litros cargados = Km/L real.
- Si el rendimiento baja de 7 km/l, revisar presión de neumáticos o filtro de aire.

## 3. Mantenimiento Preventivo (Cada 5.000 km)
- [ ] Cambio de aceite y filtro.
- [ ] Rotación de neumáticos.
- [ ] Revisión de pastillas de freno.
- [ ] Revisión de niveles de líquido refrigerante.

## 4. Regla de Oro
- El 10% de cada pago de flete debe apartarse en una caja de ahorro **exclusiva para el vehículo**. Nunca uses ese dinero para gastos personales.
